# Panto - Modern & Minimalist Furniture Store 🪑

**Panto** is a modern, responsive, and minimalist e-commerce landing page crafted for interior design enthusiasts and online furniture retailers. The platform provides an elegant digital storefront experience, showcasing premium interior solutions with a sleek user interface and smooth navigation.

---

## 🎯 Who Can Benefit from This Project?

- **Furniture Brands & Retailers:** Looking for an aesthetic, high-converting digital storefront to present their collections, pricing, and services.
- **Interior Designers & Studios:** Who need a professional portfolio and showcase page to present projects, materials, and luxury styling services.
- **Frontend Developers & Students:** Seeking a solid reference project to study modern Bootstrap 5 integration, clean HTML/CSS architecture, and responsive UI patterns.
- **Homeowners & Customers:** Enjoying a seamless browsing experience to discover modern furniture ideas, pricing, and customer feedback.

---

## ✨ Features in Detail

### 1. Navigation & Search Bar
- **Responsive Navigation Bar:** Includes smooth collapse toggling for mobile devices, categorized dropdown menus (Living Room, Bedroom, Dining Room), and direct links to sections.
- **Header Search Bar:** An integrated, styled search field ready for catalog queries and item filtering.
- **Quick Cart Access:** Dedicated shopping bag shortcut leading to the cart overview.

### 2. Value Proposition & Services ("Why Choosing Us")
- Highlights the core company strengths (luxury facilities, affordable pricing, and wide variety of choices) with direct call-to-action indicators.

### 3. Interactive Best-Selling Products Carousel
- **Category Filter Tabs:** Interactive tab navigation (Chairs, Beds, Sofas, Lamps) allowing users to switch contexts easily.
- **Multi-Item Slider:** Dynamic carousel powered by Bootstrap, showcasing items with clear imagery, names, sub-descriptions, star rating breakdowns, prices, and quick "Add to Cart" action buttons with user feedback.

### 4. Experience & Materials Showcase
- **Craftsmanship & Quality Spotlight:** Detailed highlight sections displaying material reliability, sustainable design approaches, and premium interior arrangement previews with asymmetric photo grids.

### 5. Client Testimonials Carousel
- **Social Proof & Reviews:** Customer testimonials slider with profile avatars, reviewer occupations, detailed reviews, and rating stars, boosting buyer confidence.

### 6. Dedicated Subpages
- **Cart Page (`cart.html`):** Standalone page prepared for shopping cart workflow.
- **Coming Soon Page (`coming-soon.html`):** Placeholder page for features and links undergoing development.

### 7. Comprehensive Footer
- Categorized footer links covering brand information, marketing services, quick category jumps, social media profiles, and legal policy pages.

## 🛠️ Technology Stack

| Technology | Purpose & Implementation |
| :--- | :--- |
| **HTML5** | Semantic markup, accessibility attributes, and modular page structure |
| **CSS3** | Custom typography, custom color palette (`#E58411`), responsive layouts, and interactive transitions |
| **Bootstrap 5.3.8** | Responsive grid system, carousel components, navigation toggling, and layout utilities |
| **Bootstrap Icons (v1.13.1)** | Lightweight SVG-based icons for ratings, shopping cart, arrows, and search bar |
| **Vanilla JavaScript (ES6)** | Handles interactive category switching and shopping cart addition alerts (`main.js`) |
